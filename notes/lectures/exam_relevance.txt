#### L2 exam relevance
  [1.1] (L2 p.29, 59-64, 88-93): Weak/conceptual. In-sample R^2 is judged against a naive benchmark (Ybar), which is the same idea as comparing to a majority-class baseline. CV accuracy is a mean of 0/1 hits, so var(Xbar) = sigma^2/n and the CLT give se of about sqrt(acc(1-acc)/n), roughly 2pp at n=400. Use it to judge whether max_leaf_nodes differences are meaningful. The baseline and the tree methods themselves are NOT in L2.
  [1.3] (L2 p.59-64, 72, 88-93): Whether RF/GB 'beat' the tree should be judged against sampling noise: small samples mean 'we need to get lucky' (p.62). The standard error of the mean and hypothesis-testing logic frame whether the accuracy gap can be told apart from zero. The bias-variance picture (p.72) is only conceptual support. Ensembles are not taught in L2.
  [1.5] (L2 p.63-64, 80): The CLT and var(Xbar) = sigma^2/n assume iid draws. p.80 states that equity returns are not independent or equal-variance, so iid-based procedures (textbook SEs, iid resampling) understate uncertainty. This supports arguing that shuffled K-fold (which treats monthly rows as exchangeable) is invalid for a time series. The time-ordered CV remedy and the bias direction must come from other lectures.
  [2.1] (L2 p.78): Direct template for 'commit before you compute': 'Before the next slide: how wide will that histogram be? Write down a number.'
  [2.2] (L2 p.56-57, 59-62, 65-70, 78-79): The pipeline estimator is exactly s_y^2 = SST/(n-1) with ddof=1 (p.56-57, code idiom np.var(..., ddof=1)). The one-desk and 1000-desk simulation mirrors 'treat the fitted line as the truth, generate 10,000 alternative histories, refit all' (p.78-79) and the repeated-sampling and 1000-means histogram demos (p.59-70). Report the distribution (mean, median, percentiles), not just one path.
  [2.3] (L2 p.56, 63-64, 71-72): Unbiasedness E[s^2] = sigma^2 (p.56) gives the martingale E[s2_{t+1}|s2_t] = s2_t. p.71-72: unbiased does not mean precise, and unbiasedness says nothing about the median. By the CLT (p.63-64), log s2_T is a sum of about 2500 iid nightly log-increments, so it is roughly normal (bell-shaped histogram) with negative drift. The median collapses while the mean is propped up by a few extreme desks. The drift formula of about -1/(n-1) needs Var(s^2) = 2 sigma^4/(n-1) and a delta-method/Jensen step, which are NOT in L2: present it as an empirical fit across n=50/500/5000 and flag the derivation.
  [2.4] (L2 p.38, 57, 79-81, 87): (a) DoF is 'the number of times you get to observe useful information about the variance' (p.57). Synthetic draws add no new information about the true sigma, and keeping the real days anchors the estimate. (b) p.80 is the direct analogue: the normal-model answer (formula/normal simulation) vs using the actual data (resampling weeks). 'The gap between them is the size of the assumption', and equity returns have calm and panic regimes. Normal VaR 2.326 sigma vs the empirical 1% quantile, and night-1 normal scenarios (excess kurtosis about 0) vs fat-tailed real returns (p.81: t is a fat-tailed normal; p.38: normal tail masses). The quantile idiom stats.t.ppf (p.87) matches norm.ppf(0.99). Parametric simulation from your own fit only reproduces your assumptions (p.79-80). Kurtosis and VaR themselves are not defined in L2.
  [3-features] (L2 p.3, 8, 18, 33, 37-42, 72-73, 80): Linear predictive regression as the base model: Yhat = f(X), E[Y|X], the multi-X linear form, fitted with smf.ols or LinearRegression. Slopes depend on units (b1 = r_xy s_y/s_x), which motivates cross-sectional standardization for comparable coefficients. The constant-sigma assumption (p.37, 41) is violated by time-varying return volatility (p.80), and large sigma hurts precision (p.71-73). Both motivate the vol-scaled target r/sigma_{t-1}. For pooled vs per-class models, var(b1) = sigma^2/((n-1)s_x^2) (p.73): pooling raises n and s_x and lowers variance, while per-class adds flexibility; this is the bias-variance trade-off (p.72) and 'need to get lucky' with small n (p.62). No lagging or look-ahead rules are in L2.
  [3-evaluation] (L2 p.29, 80, 84-97, 100-105): Forecast error = noise + estimation error (p.100-101). With returns, estimation error can make a fitted model worse than a naive forecast, so R2_OOS can be negative, whereas in-sample R^2 >= 0 (p.29) against in-sample Ybar. The R2_OOS definitions (vs trailing mean, vs zero) are NOT in L2; L2 supplies the 1 - SSE/SST structure. t-stats, CIs and p-values for predictive slopes, with manual non-zero nulls (p.84-97). Default SEs are 'nonrobust' and returns violate their assumptions, so use robust SEs (named only, p.80) or bootstrap resampling (p.80; iid resampling ignores serial dependence). The placebo test is analogous to the null-hypothesis logic and simulated null distributions (p.88-93, 78-79). PIs widen away from Xbar (p.103-105), so be cautious when forecasting in out-of-range regimes.
  [3-portfolio] (L2 p.47-49, 56-57, 94-97): Use excess returns (p.47). The total-risk decomposition sigma_i^2 = beta_i^2 sigma_M^2 + sigma^2(eps) and factor covariance support risk discussion. Risk-parity 1/sigma uses ddof=1 volatility. 'Does the forecast portfolio beat EW?' can be tested L2-style: regress strategy excess returns on the benchmark excess returns and test H0: alpha = 0 with the t-stat and p-value (p.94-95; alpha as a performance benchmark, p.49). Test beta = 1 by hand (p.96-97) to see whether the strategy just levers the benchmark. Sharpe ratios and costs are not in L2.
  [3-writeup] (L2 p.46, 78-80): Reporting philosophy: 'Neither number is wrong; they answer the question under different assumptions, and the gap between them is the size of the assumption.' This supports reporting results under several schemes and SE methods and defending each assumption. Keep true parameters distinct from estimates (p.46).
